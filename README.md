## ✨ Key Features Matrix

### 🎙️ Core Video Infrastructure
- **Peer-to-Peer & Group Streaming**: Low-latency WebRTC audio/video powered by Twilio's global media servers.
- **Media Pre-Check Preview**: Test camera and microphone permissions before entering any meeting room.
- **Media Mute Controls**: Toggle camera video and microphone audio on/off with visual fallback avatars.
- **Tile-Level & Room Fullscreen**: Expand individual participant feeds or the entire meeting to monitor size.
- **Live Room Analytics**: Call duration timer (`MM:SS`) and active participant count badge.

### 💻 Phase 1: Real-Time Collaboration
- **Screen Sharing**: One-click screen/window/tab sharing via WebRTC display media.
- **In-Call Side Chat**: Real-time peer-to-peer messaging via WebRTC `LocalDataTrack` with unread badges.
- **Floating Emoji Reactions**: Animate emojis (`👏`, `❤️`, `👍`, `🎉`, `😂`, `🔥`, `🙌`) directly over video cards.
- **Virtual Hand Raise**: Alert meeting participants with a glowing hand badge and toast notifications.

### 👑 Phase 2: Dynamic Layouts & Moderation
- **Grid vs. Speaker View**: Switch between multi-participant grid layout and spotlight Speaker View.
- **Dominant Speaker Detection**: Twilio `dominantSpeakerChanged` listener auto-focuses active speakers with glowing borders.
- **Host Controls**: First participant becomes `👑 HOST` with privileges to **Mute All**, mute individual users, or **Kick Participants**.

### 🤖 Phase 3: AI Intelligence & Privacy
- **AI Live Closed Captions**: Speech-to-text transcriptions generated by browser Web Speech API and broadcast live.
- **AI Camera Background Blur**: Instant camera background blurring filter for privacy protection.

## 🚀 Quick Start Guide

### 1. Prerequisites
- **Python 3.12+** installed on your system.
- A **Twilio Account** ([Sign up free at twilio.com](https://www.twilio.com)).

### 2. Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Chaitanyasarkate/flask-twilio-video.git
   cd flask-twilio-video
   ```

2. **Install Python dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure Environment Variables**:
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```

   Fill in your Twilio credentials in `.env`:
   ```env
   TWILIO_ACCOUNT_SID=ACXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
   TWILIO_API_KEY_SID=SKXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
   TWILIO_API_KEY_SECRET=your_twilio_api_key_secret_here

   FLASK_ENV=development
   SECRET_KEY=super-secret-key-change-in-production
   PORT=5000
   ```

4. **Launch the Application**:
   ```bash
   python app.py
   ```

   Open your browser at `http://localhost:5000`.

## 🔌 API Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/` | Serves the HTML5 Single Page Application. |
| `GET` | `/health` or `/api/health` | Health check endpoint returning backend & Twilio status. |
| `POST` | `/api/token` | Generates a JWT Video Access Token for an identity and room. |

### Sample Token Request (`POST /api/token`):
```json
{
  "identity": "Alex Johnson",
  "room": "Design-Sync"
}
```

### Sample Token Response (`200 OK`):
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "identity": "Alex Johnson",
  "room": "Design-Sync"
}
```

## ☁️ Render Cloud Deployment

The repository includes a pre-configured `render.yaml` for instant deployment on [Render](https://render.com):

1. Connect your GitHub repository to Render Dashboard.
2. Select **Web Service** and choose `Chaitanyasarkate/flask-twilio-video`.
3. Add Environment Variables: `TWILIO_ACCOUNT_SID`, `TWILIO_API_KEY_SID`, and `TWILIO_API_KEY_SECRET`.
4. Click **Deploy**! Live at: `https://flask-twilio-video.onrender.com`.
